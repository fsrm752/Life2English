# Life2English

**生活场景驱动的英语学习 Skill** —— 把一句真实生活/校园场景描述，变成一次完整的英语学习闭环：

```
场景输入 → 场景识别 → 学习任务生成 → 情境互动 → 表达反馈 → 迁移练习 → 学习总结
```

- **技能定义与安装入口**：[SKILL.md](SKILL.md)
- **输入输出协议**：[references/protocol.md](references/protocol.md)

---

## 快速开始

**在线体验**：<https://life2english.app.workbuddy.host/> —— 点开即用，无需安装任何东西。

**环境要求**（本地运行）：Python 3.10+（开发验证环境：Python 3.13.12 / Windows）。**无需安装任何第三方依赖。**

### 方式一：可视化界面（推荐用于演示）

双击 **`启动演示界面.bat`**，浏览器自动打开 `http://127.0.0.1:8770`。
也可手动启动（跨平台）：

```bash
python -X utf8 scripts/web_server.py            # 默认 8770，自动打开浏览器
python -X utf8 scripts/web_server.py --port 8771 --no-browser
```

界面从上到下依次是 ①描述场景 → ②学习任务 → ③情境互动 → ④表达反馈 → ⑤迁移练习 → ⑥学习总结，
侧栏列出全部支持的场景（点击可直接开始）。

> 界面**只调用** `scripts/skill_api.py` 的 JSON 协议，不含任何业务逻辑实现 ——
> 界面、命令行、智能体三条入口共用同一套逻辑。

### 方式二：交互式学习（命令行）

```bash
python scripts/life2english_cli.py     # 等价入口：python main.py
```

操作流程：主菜单输入 `1` → 描述场景（如 `我想在咖啡店点单`）→ 按提示完成
「学习任务 → 情境互动 → 表达反馈 → 迁移练习 → 学习总结」→ 回车返回主菜单 → `2` 退出。

互动中：`done` 提前结束；`重答` 撤回上一条回答；迁移练习中输入 `跳过` 跳过；`退出` 返回主菜单。

### 方式三：非交互式协议（面向智能体 / 程序）

以 JSON 进 JSON 出：

```bash
echo '{"action":"recognize","input":"我想在咖啡店点单"}' | python scripts/skill_api.py
echo '{"action":"run","scene_id":"campus_canteen","answers":["Could I get a set meal, please?"]}' \
  | python scripts/skill_api.py
```

支持的 action：`list_scenes` / `recognize` / `task` / `interact` / `feedback` / `transfer` / `summary` / `run` / `version`。

### 当前支持的场景（8 个）

| 主题 | 场景 | 触发示例 |
|---|---|---|
| 校园生活 | 介绍大学生活 | `介绍大学生活` |
| 校园生活 | 宿舍生活与舍友沟通 | `我想练习和舍友用英语沟通` |
| 校园生活 | 社团招新与自我介绍 | `我想练习社团招新` |
| 学习生活 | 课堂提问与答疑 | `我想练习在课堂上向老师提问` |
| 生活助手 | 咖啡店点单 | `我想在咖啡店点单` |
| 生活助手 | 食堂点餐与沟通 | `我想在食堂点餐` |
| 生活助手 | 与外国同学讨论电影 | `想和外国同学讨论电影` |
| 实习就业 | 兼职面试与工作沟通 | `我想练习英文兼职面试` |

不支持的具体场景（如「健身房退卡」）会走**兜底流程**：明确告知暂不支持 → 推荐最接近的 2–3 个场景 → 选择继续或重新描述。

## 设计要点

- **场景识别**：核心词 / 扩展词加权匹配（core=3 分、extra=1 分），区分「完全匹配 / 部分匹配 / 兜底推荐」，不做关键词硬套；
- **模板与逻辑分离**：场景数据集中在 `data/scenarios.json`，新增场景无需改代码；
- **本地反馈引擎**：覆盖拼写、大小写、a/an、主谓一致、名词数、词性、时态提示、常见中式表达等规则，
  问题与建议**分级展示**，并带误报防护；
- **三条入口一套逻辑**：界面、命令行、智能体协议均调用 `scripts/skill_api.py`，不存在第二份实现；
- **零依赖运行**：仅使用 Python 标准库，无需网络、无需密钥。

## 能力限制（如实说明）

- 仅支持 **8 个预设场景**，其余走兜底推荐（不做硬套匹配）；
- 表达反馈为本地规则引擎：覆盖拼写、大小写、a/an、主谓一致、名词数、词性、时态提示、常见中式表达等有限类型，**语义通顺度、复杂语法、地道性无法可靠判断**（界面中同步声明）；
- 互动对话为模板化应答，非真实模型对话；
- Web 界面为**本地单机演示**形态：默认仅绑定 `127.0.0.1`，无多用户 / 账号 / 持久化能力；
- 界面自动化覆盖有限：已用无头浏览器完成关键路径真实渲染验证（错误提示、场景识别、学习任务渲染）；多轮对话、迁移练习、学习总结等全流程的端到端界面自动化尚未覆盖；
- 不调用外部 API、不产生费用、无需密钥；未来模型接入接口已预留（`scripts/life2english/model_api.py`）。

## 安装与打包

本仓库目录结构即技能包结构：`SKILL.md` 位于技能目录根，子资源含
`references/` + `scripts/` + `templates/`，并附 `web/` 可视化界面。

- **打包**：将本仓库内容打包为 zip，顶层目录名使用 `life2english/`，即可作为技能包分发；
- **安装**：在 WorkBuddy 左侧菜单【专家·技能·连接器】→【技能】→【添加技能】中导入该 zip，
  或解压到用户技能目录。
