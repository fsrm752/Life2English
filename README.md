# Life2English

**生活场景驱动的英语学习 Skill** —— 把一句真实生活/校园场景描述，变成一次完整的英语学习闭环：

```
场景输入 → 场景理解 → 学习任务生成 → 情境互动 → 表达反馈 → 迁移练习 → 学习总结
```

支持**任意合理的沟通场景**（咖啡店点单、向教授申请延期交作业、与房东沟通房屋维修、健身房退卡……），
不限于预设列表。

- **技能定义与安装入口**：[SKILL.md](SKILL.md)
- **本地脚本输入输出协议**：[references/protocol.md](references/protocol.md)

---

## 这是什么

本技能的核心是**一套通用教学流程**，由运行环境中的 AI 模型执行：

- 读到用户描述的场景 → 理解背景、角色、沟通目标 → 生成个性化学习任务 →
  扮演交流对象与用户对话 → 给出区分「错误 / 不自然 / 语境不合适」的反馈 →
  设计迁移练习 → 总结学习成果。

**预设的 11 个场景只是参考示例与质量基准**，用来展示「一次合格练习长什么样」，不是支持范围的上限。

同时，仓库内附一套**纯标准库的本地脚本**（CLI + JSON 协议），用于无模型环境下的演示与自动化回归测试。
本地脚本只能查预设模板，**不能动态生成**——两者的差别详见下文「能力与轨道」。

### 两种运行轨道（能力不同，请勿混淆）

| 轨道 | 运行方式 | 能力 | 用途 |
|---|---|---|---|
| **A · 主路径** | 在 WorkBuddy / 智能体环境中运行 | 由环境中的 AI 模型读取 `SKILL.md` 并执行 → 可**动态生成**任意合理场景的学习任务、动态推进对话、做语义级反馈 | 面向学习者的正式使用 |
| **B · 本地脚本** | 直接运行 `scripts/` | **仅** 8 个预设场景模板 + 本地规则引擎，**不能动态生成** | 本地回归测试、无模型环境演示 |

## 快速开始

**环境要求**（本地脚本）：Python 3.10+（开发验证环境：Python 3.13.12 / Windows）。
**无需安装任何第三方依赖。**

### 方式一：交互式学习（命令行）

```bash
python scripts/life2english_cli.py     # 等价入口：python main.py
```

操作流程：主菜单输入 `1` → 描述场景（如 `我想在咖啡店点单`）→ 按提示完成
「学习任务 → 情境互动 → 表达反馈 → 迁移练习 → 学习总结」→ 回车返回主菜单 → `2` 退出。

互动中：`done` 提前结束；`重答` 撤回上一条回答；迁移练习中输入 `跳过` 跳过；`退出` 返回主菜单。

> 交互式 CLI **仅用于本地测试与调试，不是最终产品**。

### 方式二：非交互式协议（面向智能体 / 程序 / 测试）

以 JSON 进 JSON 出：

```bash
echo '{"action":"recognize","input":"我想在咖啡店点单"}' | python scripts/skill_api.py
echo '{"action":"run","scene_id":"campus_canteen","answers":["Could I get a set meal, please?"]}' \
  | python scripts/skill_api.py
```

支持的 action：`list_scenes` / `recognize` / `task` / `interact` / `feedback` / `transfer` / `summary` / `run` / `version`。

## 设计要点

- **通用教学流程**：场景理解 / 任务生成 / 角色扮演 / 反馈 / 迁移 / 总结六段流程由 `SKILL.md` 定义，
  对任意场景通用，不为单个场景写完整程序；
- **示例与逻辑分离**：参考场景数据集中在 `data/scenarios.json`，新增示例无需改代码；
- **本地反馈引擎**：覆盖拼写、大小写、a/an、主谓一致、名词数、词性、时态提示、常见中式表达等规则，
  问题与建议**分级展示**，并带误报防护；
- **零依赖运行**：本地脚本仅使用 Python 标准库，无需网络、无需密钥。

## 能力与限制（如实说明）

- **不调用外部 API、不产生费用、不需要密钥**；
- **轨道 A（模型环境）** 可动态生成学习任务、可做语义级反馈；但**不保证**内容绝对正确 ——
  涉及真实业务政策、机构规定、价格、法律等事实时以官方信息为准；
- **轨道 B（本地脚本）** 仅 11 个参考示例场景 + 本地规则引擎：
  - 表达反馈覆盖拼写、大小写、a/an、主谓一致、名词数、词性、时态提示、常见中式表达等**有限类型**，
    **语义通顺度、复杂语法、地道性无法可靠判断**；
  - 情境应答为**模板化**，不是真实模型对话；
- 本仓库不含 Web 端 / 独立应用 / 服务端；未来模型接入接口为 `scripts/life2english/model_api.py`（默认纯本地）。

## 安装与打包

本仓库目录结构即技能包结构：`SKILL.md` 位于技能目录根，子资源含
`references/` + `scripts/` + `templates/`。

- **打包**：将本仓库内容打包为 zip，顶层目录名使用 `life2english/`，即可作为技能包分发；
- **安装**：在 WorkBuddy 左侧菜单【专家·技能·连接器】→【技能】→【添加技能】中导入该 zip，
  或解压到用户技能目录。
